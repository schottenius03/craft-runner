# CraftRunner

**Course project:** Android Mobile Application  
**Description:** An Android mobile application demonstrating UI design, data handling, and core Android development concepts using Java and Android Framework.

## 📌 Overview

Craft Runner is a mobile app built during the Mobile Apps Android course (PRG1050).  
The project showcases key Android development skills, including user interface design, activity lifecycle management, data storage with SQLite, and app navigation using Jetpack components.
